# INKBOUND — GAME DESIGN

## Core Fantasy

You are a tiny living ink creature inside a magical storybook world.

## Core Mechanic

The player creates magical ink drawings.

Drawings can eventually become gameplay objects or effects.

Examples under consideration:
- lines → bridges
- circles → magical objects
- closed shapes → platforms
- symbols → spells/effects

These are possibilities, not finalized mechanics.

## First Prototype

The first prototype should prove:

1. Player can enter drawing mode.
2. Player can draw.
3. The stroke is visible.
4. Stroke points are captured.
5. The system can later interpret those points.

Do not build the full game before the drawing mechanic is fun.

## Art Direction

Cute hand-drawn fantasy.
Storybook illustration.
Thick imperfect outlines.
Chunky readable silhouettes.
Paper/ink presentation.
Restrained accent colors.
Stylized rather than realistic.
