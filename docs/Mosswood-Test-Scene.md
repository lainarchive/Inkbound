# Mosswood Test Scene

The M1 prototype now includes a small server-built Mosswood clearing so the
drawing interaction can be tested in a recognizable Inkbound space.

It includes:

- a spawn pad and illustrated stepping-stone path
- a paper-colored drawing clearing with an illuminated inkstone
- simple trees, flowers, clearing stones, and a Mosswood sign
- warm evening lighting and a light storybook atmosphere

The scene is intentionally disposable. It is created in a folder named
`Workspace/InkboundMosswood` when the server starts and does not yet include
creatures, capture logic, or progression.
