# INKBOUND — TASKS

## Current Milestone

M1 — Drawing Prototype

### Goal

Prove that drawing magical ink in the world feels good.

### Required

- drawing input
- visible stroke
- stroke point collection
- clean start/stop behavior
- basic cleanup

### Not Required Yet

- shape recognition
- procedural bridges
- platforms
- spells
- progression
- combat
- inventory
- monetization
- large world
